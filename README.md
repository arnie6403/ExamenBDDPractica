# 📊 Examen BDD Práctica - Normalización de Base de Datos (3FN)

Proyecto académico enfocado en el diseño relacional de bases de datos, estructurado hasta la **Tercera Forma Normal (3FN)** utilizando Oracle SQL Developer y desplegado en la web mediante GitHub Pages.

## 🛠️ Tecnologías Utilizadas
* **Base de Datos Local:** Oracle Database / Oracle SQL Developer (`NUMBER`, `VARCHAR2`)
* **Estructura del Esquema:** Tablas normalizadas (`clientes`, `productos`, `pedidos`, `detalle_pedidos`)
* **Frontend y Despliegue:** HTML5, CSS3 y GitHub Pages

*Desarrollado para la gestión eficiente de datos relacionales.*
